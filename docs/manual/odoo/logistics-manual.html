第一章 系统概述

本系统基于 Odoo 19 企业版进行二次开发，核心业务模块为 zhao_logistics，覆盖中、日、韩三国跨境物流全链路管理。本手册面向业务操作人员及技术运维人员，详细说明各功能模块的操作流程与最佳实践。

全链路流程图

跨境物流业务从客户下单至最终签收，全程在系统中流转。以下为完整链路及各环节对应系统模块：

📦 客户下单 → 🏭 仓库入库 → 📋 嵌套打包 → 🚢 集装箱装载 → ⚓ 船运 → 🏗️ 到港派送 → ✍️ 签收
环节系统模块关键动作
客户下单销售订单 / 物流订单客户在系统创建物流订单，填写收发件人、货物信息、运输方式
仓库入库仓库 → 入库仓库人员对到货进行入库登记，生成入库单（stock.picking incoming）
嵌套打包仓库 → 打包管理将货物按运输要求打包，生成唯一 package 编码，支持嵌套包装
集装箱装载集装箱管理将打包后的货物装进集装箱，记录封号、重量、体积
船运航次管理创建航次，绑定集装箱，关联船公司、船名、航次号、ETD/ETA
到港派送派送管理到港登记后分配末端派送，生成派送单
签收派送管理末端派送员确认签收，更新订单状态为已完成

第二章 订单管理

2.1 创建物流订单

物流订单是跨境物流业务的核心单据，记录客户委托的运输需求。创建入口：订单 → 物流订单 → 新建。

必填字段

字段说明备注
客户选择已存在的客户伙伴可先创建客户档案
运输方式海运/空运/铁路/陆运在配置中预定义
始发地发货仓库/地址自动关联仓库地址
目的地最终收货地址末端派送目标
货物明细品名、数量、重量、体积支持多行货物
预计发货日期客户期望的发货时间用于排期参考

操作步骤

  1. 进入新建页面 — 点击 订单 → 物流订单 → 新建，系统自动生成订单编号（前缀 LOG）。
  2. 填写客户信息 — 选择客户伙伴，系统自动带出默认联系人、地址、联系方式。
  3. 填写运输信息 — 选择运输方式、始发地、目的地、运输条款（如 FOB、CIF）。
  4. 添加货物明细 — 在订单行表格中添加货物，支持批量导入（Excel 模板）。
  5. 保存为草稿 — 点击"保存"，订单状态为 草稿。

💡 提示：货物明细支持按件数、毛重、净重、体积、HS 编码录入，为后续清关文件生成准备数据。

2.2 订单确认与执行

草稿订单经过内部审核后确认执行。确认后系统自动触发后续仓库操作。

  1. 审核订单 — 在物流订单列表中选择待确认订单，点击"确认"按钮。
  2. 系统自动动作 — 确认后订单状态变为 已确认，系统自动：
    • 生成入库单（待处理）
    • 更新货物库存预留
    • 发送通知邮件给仓库操作员
  3. 执行流转 — 仓库操作员完成入库后，订单进入"执行中"状态。

⚠️ 注意：订单确认后不可直接删除。如需取消，需使用"取消"按钮，系统将自动取消关联的入库单。

2.3 订单状态跟踪

物流订单的状态机反映货物在跨境链路中的实时位置：

状态说明下一步操作
草稿新建未确认确认订单
已确认已确认待入库仓库入库
执行中已入库，进入打包/装箱/航次流程按流程推进
已出运已装船/已发运到港登记
派送中已到港，末端派送进行中签收确认
已完成已签收—
已取消订单取消—
异常操作过程中出现异常进入异常工作台处理

在订单详情页的"跟踪"选项卡中，可以查看完整的时间线日志，记录每一步操作人、操作时间与备注。

2.4 订单异常处理

当订单在任意环节遇到问题（如货物破损、信息不符、清关延误），操作员可在订单详情页点击"标记异常"按钮。

  1. 标记异常 — 在订单表单中点击"标记异常"，选择异常类型（货物破损/信息缺失/清关问题/其他）。
  2. 填写异常描述 — 详细描述问题内容、涉及方、建议处理方式。
  3. 系统自动动作 — 异常信息同步至异常工作台，通知运营经理。
  4. 解除异常 — 问题解决后，运营经理在异常工作台点击"解除异常"，订单恢复原状态继续流转。

第三章 仓库操作

3.1 入库操作（stock.picking incoming）

当客户货物到达仓库时，仓库操作员执行入库登记。系统基于 Odoo stock 模块的 stock.picking 模型，类型为 incoming。

操作步骤

  1. 查看待处理入库单 — 进入 仓库 → 入库单，列表显示所有状态为"待处理"的入库单。
  2. 执行入库 — 打开入库单，核对货物信息（品名、数量、SKU），确认无误后点击"验证"按钮。
  3. 打印入库标签 — 验证后系统提示打印入库标签，贴于货物外包装。
  4. 更新库存 — 入库验证后，系统自动增加库存数量，更新库存位置。

💡 提示：支持扫码枪/PDA 扫码入库，快速匹配预生成的入库单。详见第十章 barcodes 模块说明。

字段说明

字段说明
入库单编号系统自动生成，前缀 IN/
来源订单关联的物流订单编号
计划日期预计到货日期
操作类型入库（incoming）
明细行产品、数量、包装单位
状态草稿 / 待处理 / 已完成 / 取消

3.2 打包管理（stock.package）

货物入库后，仓库操作员根据运输要求进行打包。打包管理基于 Odoo stock.quant.package 模型扩展，支持嵌套包装（大箱套小箱）。

操作步骤

  1. 创建包裹 — 进入 仓库 → 打包管理 → 新建，选择关联的入库单/订单。
  2. 选择包装类型 — 选择纸箱、木箱、托盘等包装类型，系统自动生成包裹编号（前缀 PKG）。
  3. 添加货物 — 从入库单明细中选择货物，确认数量。
  4. 嵌套包装（可选） — 如果大箱内含多个小箱，可在"子包裹"关联中绑定已有包裹，实现多级嵌套。
  5. 打印面单 — 保存后点击"打印面单"，生成运输标签贴于外包装。
  6. 确认包裹 — 确认无误后点击"标记完成"，包裹进入待装状态。

包裹状态

状态说明
草稿新建未确认
已打包打包完成，待装集装箱
已装柜已装入集装箱
已出运随航次出运

3.3 拼箱池管理（LCL Consolidation）

拼箱（Less than Container Load）是跨境物流中多个客户共享一个集装箱的运输模式。拼箱池管理模块用于集中管理待拼箱的货物。

操作流程

  1. 将货物加入拼箱池 — 在打包管理页面，选择"加入拼箱池"，系统将该包裹加入拼箱池看板。
  2. 按目的地聚合 — 拼箱池看板按目的地港口/航次维度聚合展示，方便操作员识别可拼箱的货物。
  3. 创建拼箱组 — 在拼箱池看板中，选择同一目的地的多个包裹，点击"创建拼箱组"，系统生成拼箱组记录。
  4. 分配拼箱组到集装箱 — 在拼箱组详情页，点击"分配集装箱"，选择一个目标集装箱完成绑定。

💡 提示：拼箱池看板实时显示当前待拼箱的总体积/总重量，帮助操作员合理规划集装箱利用率。

第四章 集装箱管理

4.1 创建集装箱

集装箱是跨境物流中标准化的运输单元。创建入口：集装箱 → 集装箱列表 → 新建。

必填字段

字段说明
集装箱编号箱号（唯一标识，如 MSCU1234567）
箱型20GP / 40GP / 40HQ / 45HQ 等
尺寸长×宽×高（mm）
最大载重箱体最大载重（kg）
皮重空箱自重（kg）
封号海关封条号
供应商集装箱租赁公司或自有
当前位置当前所在仓库/堆场

操作步骤

  1. 新建集装箱 — 填写箱号、箱型、尺寸、载重等基本信息。
  2. 记录封号 — 填写海关封条号，用于后续清关核对。
  3. 保存 — 保存后集装箱状态为 空箱，可进入装箱操作。

4.2 装箱操作

将已打包的货物装入集装箱，记录装箱明细。

  1. 进入装箱页面 — 在集装箱详情页点击"装箱操作"，或进入 集装箱 → 装箱操作。
  2. 选择货物 — 从待装列表中选择包裹/拼箱组，支持多选。
  3. 确认装箱 — 系统自动计算已装体积/重量，如果超出箱体容量则提示警告。
  4. 完成装箱 — 点击"完成装箱"，集装箱状态变更为 已装箱。
  5. 打印装箱清单 — 装箱完成后可打印装箱清单（Packing List），用于清关和随船文件。

⚠️ 注意：装箱时系统会校验体积和重量上限。如果超载，需调整货物或更换更大箱型。

4.3 清关申报文件生成

根据集装箱内的货物明细，系统自动生成标准清关申报文件。

可生成的文件类型

文件类型说明生成入口
报关单（Customs Declaration）向海关申报的正式单据集装箱详情页 → 生成清关文件
装箱单（Packing List）货物装箱明细清单
商业发票（Commercial Invoice）商业交易凭证，含金额、HS 编码
舱单（Cargo Manifest）船公司向海关申报的货物总清单
  1. 选择文件模板 — 系统预置中日韩三国的标准报关模板，按目的地自动匹配。
  2. 预览并确认 — 生成文件前可预览数据，确认 HS 编码、金额、重量等信息准确。
  3. 生成并下载 — 确认后生成 PDF/Excel 文件，支持批量下载。
  4. 归档 — 生成的文件自动关联到集装箱记录，供后续查阅。

4.4 集装箱状态跟踪

集装箱在生命周期中经历以下状态流转：

状态说明

已装箱货物已装入
已绑航次已分配到航次
已出运随航次离港
已到港到达目的港
已拆箱目的港拆箱，货物进入派送环节
已返空空箱返回堆场

第五章 航次管理

5.1 创建航次

航次代表一次船舶运输任务。创建入口：航次 → 航次列表 → 新建。

必填字段

字段说明
航次号船公司航次编号（如 COSCO001E）
船名船舶名称
船公司承运人/船公司
始发港起运港口
目的港目的港口
ETD（预计离港）预计离港时间
ETA（预计到港）预计到港时间
截关时间最晚报关时间
截单时间最晚提交文件时间
  1. 填写航次信息 — 录入航次号、船名、船公司、港口及时间信息。
  2. 保存航次 — 保存后航次状态为 计划中。

5.2 绑定集装箱

将已装箱的集装箱分配到航次。

  1. 进入航次详情 — 打开目标航次记录。
  2. 添加集装箱 — 在"集装箱"子表中点击"添加"，选择已装箱的集装箱。
  3. 确认绑定 — 绑定后集装箱状态自动更新为 已绑航次。
  4. 确认出运 — 实际离港后，点击"确认出运"，航次状态更新为 已出运，关联集装箱同步更新。

💡 提示：一个航次可绑定多个集装箱。航次详情页的"集装箱"子表会汇总显示总箱数、总毛重、总体积。

5.3 航次跟踪

航次跟踪提供可视化的时间线视图，帮助运营人员掌握航次进度。

航次状态说明
计划中航次已创建，尚未开始装货
装货中集装箱正在装船
已出运船舶已离港，航行中
已到港船舶已抵达目的港
已完成所有集装箱已卸船并完成交接
已取消航次取消

航次详情页的"跟踪日志"选项卡按时间线记录每一步操作，包括实际操作时间与计划时间的对比，便于分析延误原因。

第六章 派送管理

6.1 到港登记

船舶抵达目的港后，操作员在系统中进行到港确认。

  1. 进入航次列表 — 找到已出运的航次，点击"到港登记"。
  2. 确认到港时间 — 填写实际到港时间（ATD），上传到港通知单（可选）。
  3. 系统自动动作 — 航次状态更新为 已到港，关联集装箱状态更新为 已到港。
  4. 拆箱操作 — 在集装箱详情页点击"拆箱"，拆箱后货物进入待派送状态。

6.2 派送分配

拆箱后的货物需要分配末端派送任务。

  1. 进入派送分配 — 进入 派送 → 派送分配，列表显示所有待派送的货物。
  2. 创建派送单 — 选择目标货物，点击"创建派送单"，系统自动生成派送单号（前缀 DEL）。
  3. 分配派送员 — 选择负责派送的司机/派送员，填写派送车辆信息。
  4. 打印派送单 — 打印派送清单，交派送员随车携带。
  5. 确认派送 — 确认后派送单状态为 派送中。

6.3 签收确认

末端派送员完成派送后，客户签收确认。

  1. 进入签收页面 — 进入 派送 → 签收确认，选择对应派送单。
  2. 录入签收信息 — 填写签收人姓名、签收时间、签收照片（可选）。
  3. 选择签收状态 — 正常签收 / 拒收 / 部分签收。
  4. 确认完成 — 点击"确认签收"，派送单状态更新为 已完成，关联物流订单状态更新为 已完成。

⚠️ 注意：如果客户拒收或部分签收，系统自动创建异常单，进入异常工作台处理流程。

第七章 退货管理

7.1 退货订单创建

当客户要求退货时，客服专员在系统中创建退货订单。

  1. 进入退货订单 — 进入 退货 → 退货订单 → 新建。
  2. 关联原订单 — 选择原始物流订单，系统自动带出原货物明细。
  3. 选择退货原因 — 从预设退货原因中选择（如质量问题、错发、拒收等）。
  4. 填写退货数量 — 确认退货的货物数量及状态。
  5. 保存 — 保存后退货单状态为 待审核。

7.2 逆向物流流程

退货审核通过后，执行逆向物流操作。

  1. 审核退货单 — 运营经理审核退货单，确认后状态变更为 已审核。
  2. 生成逆向入库单 — 系统自动创建退货入库单（类型为 return），仓库人员等待退货到货。
  3. 退货入库 — 退货到达仓库后，仓库操作员在入库单中执行验证，完成退货入库。
  4. 货物检查 — 仓库人员检查退货货物状态，在系统中记录检查结果（可重新上架/需报废/需维修）。

7.3 退款单关联

退货入库完成后，财务人员处理退款。

  1. 创建退款单 — 在退货单详情页点击"创建退款单"，系统自动带出退款金额信息。
  2. 确认退款金额 — 财务人员根据退货检查结果确认最终退款金额（可能扣除折旧/损坏费用）。
  3. 执行退款 — 确认后执行退款，系统记录退款流水号。
  4. 完成 — 退款完成后退货单状态更新为 已完成。

第八章 清关管理

8.1 报关文件生成

清关专员按集装箱维度生成标准报关文件。系统支持批量生成，减少重复工作。

报关单（Customs Declaration）

报关单是向海关申报货物的核心文件。系统根据集装箱内货物明细自动生成。

数据项数据来源
发货人信息订单始发地客户信息
收货人信息订单目的地客户信息
货物描述货物明细行的品名
HS 编码货物明细行录入的 HS 编码
数量/重量/体积货物明细行汇总
集装箱号关联集装箱编号
航次信息关联航次号、船名、ETD

装箱单（Packing List）

详细列出每个包裹/箱件的内装货物信息，包括件数、毛重、净重、体积。

商业发票（Commercial Invoice）

商业交易凭证，包含货物价值、成交方式、货币单位等信息。系统从订单行中的货物价值字段自动提取。

舱单（Cargo Manifest）

汇总航次下所有集装箱的货物总清单，报船公司及目的港海关。

  1. 选择集装箱 — 在集装箱列表中选择目标集装箱，点击"生成清关文件"。
  2. 选择文件类型 — 勾选需要生成的文件类型（报关单/装箱单/商业发票/舱单）。
  3. 预览 — 系统生成文件预览，确认数据无误。
  4. 生成并下载 — 点击"生成"，文件以 PDF 格式保存，自动关联到集装箱记录。

8.2 集装箱报关状态

清关专员在清关管理中跟踪每个集装箱的报关进度。

报关状态说明
待申报文件已生成，尚未提交海关
已申报已提交海关申报
海关放行海关审核通过，已放行
查验中海关抽查查验
退关海关退回或申报撤销

在 清关 → 集装箱报关状态 页面，可按航次、集装箱号、报关状态进行筛选和批量操作。

第九章 异常工作台

9.1 异常单查看与处理

异常工作台是统一处理全链路异常事件的中心。进入 异常 → 异常工作台。

异常单字段

字段说明
异常编号系统自动生成，前缀 EXP
来源单据关联的物流订单/入库单/集装箱/航次
异常类型货物破损 / 信息缺失 / 清关延误 / 派送失败 / 其他
严重级别低 / 中 / 高 / 紧急
状态待处理 / 处理中 / 已解决 / 已关闭
处理人当前负责处理的人员
创建时间异常产生时间
  1. 筛选异常单 — 使用过滤器按状态/类型/级别筛选。
  2. 查看详情 — 点击异常编号进入详情页，查看完整异常描述和关联单据。
  3. 处理异常 — 填写处理意见、上传附件（如照片、证明文件），点击"开始处理"。
  4. 解决/关闭 — 问题解决后点击"标记已解决"，经确认后关闭异常单。

9.2 异常分类与升级

异常分类

异常类型典型场景默认处理人
货物破损入库或到港时发现货物外包装破损仓库操作员
信息缺失订单缺少 HS 编码或货物价值信息客服专员
清关延误海关查验或其他清关问题导致延误清关专员
派送失败末端派送无人签收或地址错误派送员
航次变更船期变更、甩柜等航次调度
其他未归类异常运营经理

升级机制

如果异常单在预设时限内未处理，系统自动升级：

  • 低级别 — 24 小时未处理 → 升级为"中"级别
  • 中级别 — 12 小时未处理 → 通知运营经理
  • 高级别 — 6 小时未处理 → 通知系统管理员
  • 紧急 — 立即通知所有相关人员

第十章 报表

10.1 业务报表列表

系统提供以下预置报表，帮助管理层和运营人员分析业务数据。

报表名称数据来源用途
订单量统计报表物流订单按日/周/月/客户维度统计订单数量与金额

10.2 报表导出

报表支持导出为多种格式，方便线下分析和存档。

  1. 进入报表 — 在 报表 菜单中选择目标报表。
  2. 设置筛选条件 — 设置时间范围、客户、航线等筛选条件。
  3. 预览 — 点击"预览"，系统生成报表数据。
  4. 导出 — 点击"导出"按钮，选择导出格式：
    • Excel（.xlsx） — 适用于数据分析和二次处理
    • PDF — 适用于打印和存档
    • CSV — 适用于系统间数据交换

💡 提示：所有报表支持自定义列、分组、排序，用户可保存常用筛选条件为"收藏视图"。
