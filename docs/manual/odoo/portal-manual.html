第一章 系统概述

1.1 门户网站定位

赵氏物流客户门户是一个面向跨境物流客户（货主 / 收货人）的客户自助服务平台。客户无需登录即可完成以下核心操作：

  • 浏览物流服务方案（FBA 头程、包裹快递、拼箱 LCL、特种货物）
  • 在线提交货物询价，系统自动在 Odoo 后台生成销售线索
  • 输入追踪单号，实时查看货物运输状态与时间线
  • 浏览常见问题 FAQ、下载资料、联系客服

门户旨在降低人工客服咨询量、提升客户响应效率，实现 7×24 小时自助服务。

1.2 技术架构说明

层级技术栈说明
前端React 18 + Vite + TypeScriptSPA 单页应用，组件化开发
后端Odoo 19 (Python)业务逻辑层，提供 REST API
API 通信RESTful JSON前端通过 fetch / axios 调用
API 前缀/zhao_logistics/public/v1/*所有公开接口统一前缀
部署Nginx 反向代理静态资源 + API 代理
架构要点
前端为纯静态 SPA，通过 REST API 与 Odoo 后端交互。所有公开接口无需认证，后端通过请求频率限制（Rate Limit）和 IP 白名单进行安全防护。

1.3 多语言支持

门户内置 i18n 国际化方案，支持以下四种语言，用户可通过页面顶部的语言切换器即时切换：

第三章 在线询价

在线询价（Quote）是门户核心功能之一。客户填写货物信息后提交，系统自动在 Odoo 后台创建 crm.lead 线索，供销售团队跟进。

3.1 进入询价页面

  1. 在门户顶部导航栏点击 「询价 Quote」 链接
  2. 页面路径为 /quote，加载询价表单
  3. 表单包含必填与选填字段，带前后端双重校验

3.2 填写货物信息

询价表单字段如下：

字段类型必填说明
起运地下拉选择是支持城市/港口选择，如"深圳"、"上海"
目的地下拉选择是如"洛杉矶"、"东京"、"汉堡"
货物品类下拉选择是如"电子产品"、"服装"、"机械设备"、"化工品"等
重量 (kg)数字输入是支持小数点，如 150.5
体积 (m³)数字输入否选填，用于拼箱/整柜估算
联系人姓名文本是客户姓名
联系人邮箱邮箱是用于接收报价回复
联系人电话文本否选填
备注文本域否特殊要求或补充说明
校验规则：重量必须大于 0；邮箱格式必须合法；必填字段为空时表单无法提交，错误提示以红色文字显示在对应字段下方。

3.3 提交询价

  1. 填写完所有必填字段后，点击表单底部的 「提交询价」 按钮
  2. 按钮进入 loading 状态，显示旋转动画，防止重复提交
  3. 前端发送 POST /zhao_logistics/public/v1/quote 请求，携带 JSON body
  4. 提交成功后，页面显示成功提示："询价已提交，我们的销售团队将在 24 小时内与您联系"
  5. 如提交失败，显示错误提示信息，客户可尝试重新提交

3.4 后台线索生成流程（Odoo crm.lead）

API 接收到询价请求后的处理流程：

  1. API 控制器接收并校验请求参数
  2. 在 Odoo crm.lead 模型中创建一条新线索，字段映射如下：
表单字段Odoo crm.lead 字段
起运地origin_port（自定义）
目的地destination_port（自定义）
货物品类cargo_category（自定义）
重量estimated_weight（自定义）
体积estimated_volume（自定义）
联系人姓名contact_name
联系人邮箱email_from
联系人电话phone
备注description
  1. 线索创建成功后，自动分配至预设的销售团队队列
  2. API 返回 { "success": true, "lead_id": 12345 } 给前端
运维提示：可在 Odoo 后台 crm.lead 列表视图的筛选器中添加"来源 = 门户询价"来区分门户渠道线索。

3.5 价格估算工具使用

询价页面同时提供价格估算工具，客户可在提交前快速获取参考价格：

  1. 在询价表单中填写起运地、目的地、货物品类、重量、体积
  2. 点击 「估算运费」 按钮
  3. 前端调用 GET /zhao_logistics/public/v1/price-estimate?origin=...&destination=...&category=...&weight=...&volume=...
  4. API 根据预设费率表返回估算价格区间（如"¥ 3,500 - ¥ 4,800"）
  5. 估算结果展示在表单下方，包含运输方式建议（如"建议使用海运拼箱"）
注意：价格估算仅供参考，实际报价以销售团队确认的正式报价单为准。

第四章 货物追踪

货物追踪（Track）功能允许客户输入追踪单号，实时查看货物运输状态与完整时间线。

4.1 输入追踪单号

  1. 点击顶部导航栏 「追踪 Track」 进入追踪页面（/track）
  2. 在页面中央的搜索输入框中输入追踪单号（Tracking Number）
  3. 点击 「查询」 按钮或按回车键
  4. 前端调用 GET /zhao_logistics/public/v1/tracking?tracking_no=...
单号格式：支持 ZL 开头的标准追踪号（如 ZL2026080012345），也支持客户自有单号（需后台配置映射）。

4.2 查看物流时间线

查询成功后，页面展示以下信息：

  • 当前状态：以醒目徽章显示（如"运输中"、"已签收"、"异常"）
  • 物流时间线：按时间倒序排列的事件列表，每项包含：
    • 事件时间戳（格式：YYYY-MM-DD HH:mm，含时区）
    • 事件描述（如"货物已抵达目的港"、"海关查验中"）
    • 事件地点
    • 状态图标（已签收 ✓ / 运输中 ⟳ / 异常 ⚠）
  • 货物概要：起运地 → 目的地、运输方式、预计到达时间
[ 物流时间线 UI 示意图 — 竖排时间轴 + 状态节点 ]

4.3 异常状态提醒

当货物出现异常状态时，追踪页面会突出显示：

  • 状态徽章变为红色（#dc2626），显示"异常"标记
  • 异常事件在时间线中以 红色背景 高亮
  • 显示异常说明文字（如"海关查验 — 需补充文件，请联系客服"）
  • 页面底部显示建议操作按钮（如"联系客服"、"查看所需文件"）

4.4 订阅状态更新通知（邮件）

客户可以订阅货物状态更新通知，当状态发生变化时自动收到邮件：

  1. 在追踪结果页面找到 「订阅更新」 按钮
  2. 点击后弹出邮箱输入框，默认填入查询时使用的邮箱（如有）
  3. 输入/确认邮箱地址，点击 「确认订阅」
  4. 前端调用 POST /zhao_logistics/public/v1/tracking/subscribe，携带 { tracking_no, email }
  5. 订阅成功后，每次该追踪号的状态更新时，系统自动发送邮件通知
邮件模板：通知邮件使用 Odoo 邮件模板，包含追踪号、当前状态、最新事件描述、追踪链接。客户可直接点击链接查看最新状态。

5.1 各服务方案详情

📦 FBA 头程服务

为亚马逊卖家提供从中国到亚马逊 FBA 仓库的全程物流服务：

📮 包裹快递服务

门到门小包裹快递，适合电商卖家和个人寄送：

  • 合作渠道：DHL、FedEx、UPS、TNT 等国际快递
  • 支持全球 220+ 国家和地区
  • 在线下单、上门揽收、全程追踪
  • 提供中港台、东南亚等专线小包服务

🚢 拼箱 LCL 服务

海运拼箱服务，适合货量不足整柜的客户：

  • 固定拼箱船期，每周/双周班次
  • 覆盖主要航线：中国→北美、欧洲、东南亚、中东
  • 提供 CFS 收货、拆箱、分货服务
  • 支持买单出口、双清包税等增值模式

⚠️ 特种货物服务

针对特殊品类货物的专业运输方案：

  • 危险品（DG）：拥有 IATA/IMDG 认证资质，支持 Class 2-9 类危险品
  • 超大件：机械设备、车辆、工业零件等超尺寸货物
  • 温控货物：冷链运输，支持温度实时监控
  • 贵重物品：高价值货物，提供全程安保与保险

第六章 帮助中心

帮助中心（Help）页面为客户提供自助查询和资料获取渠道。

6.1 FAQ 浏览（按分类展开）

FAQ 页面采用分类折叠面板（Accordion）布局：

  • 按主题分类：运费与报价、货物追踪、报关清关、仓储配送、账户与支付
  • 点击分类标题展开该分类下的问题列表
  • 点击具体问题展开答案文本
  • 支持同时展开多个分类
  • 顶部提供搜索框，支持关键词模糊搜索 FAQ 内容

FAQ 数据通过 GET /zhao_logistics/public/v1/faq 获取，支持按分类和语言筛选。

6.2 资料下载（填写邮箱 → 请求发送）

客户可申请下载物流相关资料（如服务指南、报价手册、合规文件等）：

  1. 在帮助中心页面找到 「资料下载」 区域
  2. 浏览可下载的资料列表，点击目标资料的 「申请下载」 按钮
  3. 弹出表单，填写姓名和邮箱地址
  4. 点击 「发送」 提交请求
  5. 前端调用 POST /zhao_logistics/public/v1/download-request
  6. 后台 Odoo 自动发送邮件，附件包含所申请的 PDF 资料
  7. 页面显示成功提示："资料已发送至您的邮箱，请查收"
安全说明：资料不直接通过前端下载，而是通过邮件发送，确保资料分发可追溯、可审计。

6.3 联系客服

帮助中心页面底部提供在线客服入口：

  • 在线客服：点击后弹出聊天窗口（集成第三方客服系统）
  • 客服热线：显示客服电话号码，支持一键拨打（移动端）
  • 客服邮箱：support@zhaologistics.com
  • 客服工作时间：周一至周五 09:00 - 18:00（UTC+8）

8.2 环境配置指南

前端项目通过环境变量配置 API 地址。创建或修改项目根目录的 .env 文件：

# .env 文件 — API 基础地址配置
VITE_ODOO_API_BASE=http://localhost:8069

# 多语言配置（可选，默认启用四种语言）
VITE_I18N_LOCALES=zh-CN,ja-JP,ko-KR,en-US

# 默认语言
VITE_I18N_DEFAULT_LOCALE=zh-CN
环境变量必填默认值说明
VITE_ODOO_API_BASE是无Odoo 服务器地址，包含协议和端口
VITE_I18N_LOCALES否四种语言启用的语言列表，逗号分隔
VITE_I18N_DEFAULT_LOCALE否zh-CN默认语言

# 开发模式

生产部署：建议通过 Nginx 将前端请求代理到 Odoo 后端，避免跨域问题。示例 Nginx 配置： 
location /zhao_logistics/public/v1/ {
    proxy_pass http://127.0.0.1:8069;

    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

location / {

    try_files $uri $uri/ /index.html;
}

8.3 常见问题

Q1: 询价提交后多久能收到回复？

标准回复时间为 24 小时内。紧急询价建议通过 WhatsApp 或热线电话联系客服。

Q2: 为什么查询追踪单号时显示"未找到"？

可能原因：单号输入错误（注意区分 0 和 O）、货物尚未被系统录入（通常在发货后 24 小时内录入）、或该单号不属于赵氏物流承运范围。建议核对单号后重新查询，或联系客服确认。

Q3: 如何切换门户语言？

点击页面顶部导航栏右侧的 🌐 语言图标，在下拉菜单中选择所需语言。当前支持中文、日文、韩文、英文。选择后自动保存，下次访问自动应用。

Q4: 门户在移动端显示异常怎么办？

门户已适配响应式布局，支持手机和平板浏览。如遇显示异常，建议尝试以下操作：清除浏览器缓存、更新浏览器至最新版本、或切换至横屏模式。如问题持续，请联系技术支持。

Q5: 资料下载后没有收到邮件？

请检查：填写的邮箱地址是否正确、邮件是否被归入垃圾邮件箱。如确认无误仍未收到，请联系客服手动发送。

Q6: 价格估算与实际报价有差异怎么办？

价格估算基于系统预设费率表，仅供参考。实际报价受燃油附加费、旺季附加费、海关查验等因素影响，以销售团队出具的正式报价单为准。建议提交正式询价获取准确报价。

Q7: 开发模式下前端无法连接 API？

请确认：

  • Odoo 服务已启动并在 localhost:8069 上监听
  • .env 文件中 VITE_ODOO_API_BASE 配置正确
  • 浏览器控制台无 CORS 错误。如有跨域问题，可在 Odoo 中配置 CORS 或使用 Nginx 代理
