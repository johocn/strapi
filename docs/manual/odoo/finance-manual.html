Odoo 19 进销存与财务公共模块操作手册

适用版本：Odoo 19 Community & Enterprise  |  更新日期：2026-08-01  |  面向对象：业务操作人员、技术运维人员

第一章 系统概述

模块概览

Odoo 19 的进销存与财务模块是超市收银、跨境物流等业务模块的公共基础。四个核心模块——采购（Purchase）、库存（Stock）、销售（Sale）、财务（Accounting）——构成完整的业务闭环。

1.1 模块关系图

采购管理 → 库存管理 → 销售管理 → 财务管理

数据流向：采购入库 → 库存流转 → 销售出库 → 财务核算

1.2 模块功能总览表

模块技术名称核心功能依赖模块
采购管理purchase采购订单、询价、收货、供应商管理stock, account
销售管理sale_management销售订单、报价、发货、客户管理stock, account
库存管理stock仓库、盘点、移库、批次/序列号product
财务管理account科目表、发票、付款、对账、报表base

1.3 数据流向说明

业务数据在模块间按以下路径流转：

  1. 采购 → 库存：采购订单确认后生成入库单，库存量自动更新。
  2. 库存 → 销售：销售订单确认后生成出库单，库存扣减。
  3. 销售 → 财务：销售订单生成客户发票，进入应收管理。
  4. 采购 → 财务：采购订单生成供应商账单，进入应付管理。
  5. 库存 → 财务：库存价值变动（收货/发货/盘点）生成会计凭证，影响资产与成本。
提示：所有模块共享同一套产品（Product）主数据和合作伙伴（Partner）主数据，保证数据一致性。

第二章 采购管理

采购管理模块（purchase）负责从供应商采购商品或服务的全流程管理，包括询价、采购订单、收货、开票以及供应商信息维护。

2.1 创建采购订单

操作步骤
  1. 导航至 采购 → 采购订单 → 新建。
  2. 选择供应商，系统自动带出预设的供应商地址、付款条款、货币等信息。
  3. 在订单行中添加产品，指定数量、单价。支持从历史采购价或上次采购价自动填充。
  4. 设置期望收货日期，该日期作为后续收货计划的参考。
  5. 点击"确认订单"——订单状态变为"采购订单"（PO），同时触发以下动作：
    • 生成RFQ编号（询价单）→ 确认后转为正式采购订单。
    • 若产品设置了"路线：补货规则"，触发补货。
    • 生成待收货的入库单据。
提示：采购订单支持"一单多行"、多收货地址、按行确认收货。如需分批收货，可使用"收货"按钮分次处理。

2.2 采购收货（入库）

操作步骤
  1. 导航至 采购 → 收货 → 待处理，查看所有待收货的采购订单。
  2. 打开目标收货单，核对产品、数量、批次（如有）。
  3. 点击"验证"按钮完成入库：
    • 全部收货：一次完成整单收货。
    • 部分收货：输入实际到货数量，剩余数量仍为待收货状态。
  4. 入库完成后，库存数量自动增加，同时生成会计入库凭证（若已配置库存估价）。
注意：收货前请确保产品已启用"可采购"属性，且仓库位置已正确配置。若启用批次管理，必须在收货时录入批次号。

2.3 供应商管理

功能路径说明
供应商列表采购 → 供应商查看所有供应商联系人，支持搜索、筛选、分组
新建供应商采购 → 供应商 → 新建填写名称、地址、税号、联系方式、付款条款等
供应商价格表采购 → 供应商价格表按产品/数量区间设置供应商专属价格
供应商评价采购 → 报表 → 供应商评价基于交货准时率、质量等维度的评分

2.4 采购报表

报表名称路径用途
采购订单分析采购 → 报表 → 采购订单分析按供应商、产品、时间段统计采购金额与数量
待收货订单采购 → 报表 → 待收货追踪尚未完成收货的采购订单
供应商历史价格采购 → 报表 → 供应商价格对比对比不同供应商的产品历史报价
采购趋势采购 → 报表 → 采购趋势按月/季度展示采购量变化趋势

第三章 销售管理

销售管理模块（sale_management）覆盖客户报价、销售订单、发货以及客户关系管理，是业务收入的核心入口。

3.1 创建销售订单

操作步骤
  1. 导航至 销售 → 销售订单 → 新建。
  2. 选择客户，系统自动带出客户地址、付款条款、价格表等信息。
  3. 添加产品行，选择数量、单价。若已配置客户价格表，单价自动填充。
  4. 设置承诺交货日期，该日期驱动后续发货计划。
  5. 确认订单——系统自动触发：
    • 生成出库单（若产品路线配置为"交付"）。
    • 生成客户发票（若设置"确认后自动开票"）。
    • 更新库存预约量（Available to Promise, ATP）。

3.2 销售发货（出库）

操作步骤
  1. 导航至 库存 → 收货 → 待处理（出库单亦在此处）。
  2. 筛选"出库"类型，找到对应销售订单的出货单。
  3. 核对产品、数量、批次/序列号。
  4. 点击"验证"完成出库，库存数量扣减，状态更新为"已完成"。
提示：支持按订单行分批发货。若客户需要部分发货，可在出货单中修改数量后验证，剩余数量自动生成新的出货单。

3.3 客户管理

功能路径说明
客户列表销售 → 客户查看所有客户，支持标签、地域、行业分组
新建客户销售 → 客户 → 新建填写名称、地址、联系人、税号、付款条款等
客户价格表销售 → 价格表按客户等级、数量区间、有效期设置销售价格
信用额度销售 → 配置 → 客户信用设置客户信用上限，超限时系统自动拦截

3.4 销售报价与订单转化

流程说明
  1. 创建报价单（Quotation）：填写客户、产品、价格，保存后状态为"报价单"。
  2. 通过邮件发送报价单给客户（系统内置邮件模板，支持PDF附件）。
  3. 客户确认后，点击"确认订单"——报价单转化为销售订单。
  4. 也可在报价单上直接点击"确认"跳过度步骤。
提示：报价单可设置有效期，过期后自动失效。支持在线报价门户，客户可在线确认。

3.5 销售报表

报表名称路径用途
销售分析销售 → 报表 → 销售分析按客户、产品、销售员、时间段分析销售额
报价转化率销售 → 报表 → 报价分析统计报价到订单的转化率与平均周期
待发货订单销售 → 报表 → 待发货追踪已确认但未完全发货的订单
销售毛利分析销售 → 报表 → 毛利分析按订单/产品维度计算销售收入与成本毛利

第四章 库存管理

库存管理模块（stock）是进销存的中枢，管理仓库位置、库存移动、盘点、批次/序列号追踪等核心功能。

4.1 仓库配置

仓库与位置结构

Odoo 使用多级位置（Location）结构管理仓库。建议配置层次：

公司仓库 (WH)
├── 收货区 (WH/Receipt)    — 采购入库暂存
├── 存储区 (WH/Stock)      — 主库存
├── 拣货区 (WH/Pick)       — 销售出库暂存
├── 包装区 (WH/Pack)       — 包装作业区
├── 发货区 (WH/Ship)       — 待发货区域
├── 报废区 (WH/Scrap)      — 不合格品
└── 盘点差异区 (WH/Inventory Loss) — 盘点差异调整
仓库配置步骤
  1. 导航至 库存 → 配置 → 仓库，点击新建。
  2. 填写仓库名称、简称、地址。
  3. 配置补货路线：选择"采购"、"制造"或"补货规则"。
  4. 设置出库/入库的默认位置。
  5. 可选：启用"多库位"、"批次管理"、"序列号管理"等高级功能。

4.2 库存盘点

操作步骤
  1. 导航至 库存 → 操作 → 盘点，点击新建。
  2. 选择盘点类型：
    • 全部盘点：对仓库中所有产品进行盘点。
    • 部分盘点：仅对指定产品/位置盘点。
  3. 点击"开始盘点"，系统生成当前库存数量作为参考。
  4. 逐行输入实际盘点数量。系统自动计算差异（数量差异 = 实盘数量 - 账面数量）。
  5. 点击"验证盘点"——差异部分自动生成库存调整单，并更新会计估价（如启用）。
注意：盘点期间建议暂停相关产品的出入库操作，避免数据冲突。启用"盘点锁库"功能可自动阻止盘点期间的库存移动。

4.3 库存调整

三种调整类型
类型操作路径说明
入库调整库存 → 操作 → 库存调整 → 新建（入库）手动增加库存，适用于盘盈、退货入库等场景
出库调整库存 → 操作 → 库存调整 → 新建（出库）手动减少库存，适用于盘亏、样品、损坏等场景
库存移库库存 → 操作 → 库存转移在同一仓库内或跨仓库移动产品库存
移库操作步骤
  1. 导航至 库存 → 操作 → 库存转移，点击新建。
  2. 选择源位置和目标位置。
  3. 添加产品行，指定移库数量。
  4. 点击"确认"——生成库存移动单。
  5. 操作员在源位置完成拣货后"验证"，到达目标位置后"验证"完成移库。

4.4 库存报表与预警

报表/功能路径用途
库存概况库存 → 报表 → 库存概况按产品/位置查看当前库存数量与价值
库存移动报表库存 → 报表 → 库存移动追踪所有出入库记录，按时间/产品/位置筛选
库存价值分析库存 → 报表 → 库存价值按成本计算方法展示库存总价值
库存预警规则库存 → 配置 → 补货规则设置最低库存量，低于阈值自动触发补货建议
滞销品分析库存 → 报表 → 滞销品识别超过设定天数未移动的产品
提示：补货规则支持"最小-最大"（Min-Max）策略，系统每日检查库存水平，自动生成采购建议或补货单。

4.5 批次/序列号管理

启用配置
  1. 导航至 库存 → 配置 → 设置，启用"批次"和/或"序列号"功能。
  2. 在产品主数据中，为每个产品设置跟踪方式：
    • 无跟踪：不启用批次/序列号。
    • 按批次：同一批产品共享一个批次号，适用于保质期管理。
    • 按唯一序列号：每个产品有唯一序列号，适用于高价值或可追溯产品。
操作场景
场景操作说明
采购收货录入批次收货时，在"批次/序列号"列输入或选择批次号，支持批量生成
销售发货选择批次发货时，系统自动建议先进先出（FIFO）的批次，也可手动选择
批次追溯在产品表单 → 批次/序列号标签页，查看该批次的全部出入库记录
保质期管理批次号可关联生产日期和有效期，系统自动预警临近过期产品

第五章 财务管理

财务管理模块（account）是企业财务核算的核心，涵盖科目表、发票、付款、对账、报表及税务管理。

5.1 会计科目表设置

科目表结构

Odoo 19 预置了多套科目表模板（中国会计准则、IFRS、US GAAP 等），安装后自动导入。

  1. 导航至 会计 → 配置 → 会计科目表。
  2. 查看所有科目列表，支持按代码、名称、类型（资产/负债/收入/费用/权益）筛选。
  3. 编辑科目：设置科目代码、名称、类型、是否允许对账、税务默认值等。
  4. 新建科目：点击"新建"，填写代码（建议遵循数字编码规则）、名称、类型和上级科目。
科目类型代码范围（示例）说明
资产1000-1999现金、银行存款、应收账款、存货、固定资产等
负债2000-2999应付账款、预收款项、应交税费等
权益3000-3999实收资本、资本公积、未分配利润等
收入4000-4999主营业务收入、其他业务收入等
费用5000-6999主营业务成本、管理费用、销售费用、财务费用等

5.2 客户发票与收款

开票流程
  1. 自动生成：销售订单确认后，点击"创建发票"或启用自动开票。
  2. 手动创建：导航至 会计 → 客户 → 发票，点击新建，选择客户、添加发票行。
  3. 核对发票金额、税率、付款条款无误后，点击"确认"。
  4. 确认后发票状态变为"已过账"，会计凭证自动生成。
  5. 发送发票给客户：点击"发送并打印"，支持PDF邮件发送。
收款操作
  1. 导航至 会计 → 客户 → 收款，点击新建。
  2. 选择客户，系统自动显示该客户的未结清发票。
  3. 在"未结清款项"标签页中勾选要结算的发票，输入收款金额。
  4. 选择收款账户（银行账户/现金）、收款日期。
  5. 点击"确认"——收款凭证过账，发票状态更新为"已付清"或"部分付款"。

5.3 供应商账单与付款

录入供应商账单
  1. 自动生成：采购收货后，点击"创建账单"。
  2. 手动录入：导航至 会计 → 供应商 → 账单，点击新建。
  3. 选择供应商，添加账单行（产品/费用），填写金额、税率。
  4. 确认过账，生成应付会计凭证。
付款操作
  1. 导航至 会计 → 供应商 → 付款，点击新建。
  2. 选择供应商，系统自动显示未结清账单。
  3. 勾选要支付的账单，确认付款金额。
  4. 选择付款账户、付款方式（银行转账/现金/支票）。
  5. 确认过账，账单标记为"已付清"。

5.4 银行对账

操作步骤
  1. 导入银行流水：导航至 会计 → 配置 → 银行账户，点击"导入对账单"。
  2. 支持 CSV/OFX/QIF 格式导入，也可手动逐笔录入。
  3. 进入"对账"界面，系统自动匹配银行流水与会计凭证（基于金额、日期、伙伴）。
  4. 手动匹配：将未匹配的银行流水拖拽到对应的发票/付款凭证上。
  5. 确认匹配后，银行流水状态变为"已对账"。
  6. 对账完成后，点击"验证"过账。
提示：Odoo 19 支持智能对账引擎，基于历史匹配规则自动推荐匹配项，大幅提升对账效率。

5.5 总账与明细账

报表名称路径说明
总分类账会计 → 报表 → 总分类账按科目展示所有过账凭证的汇总与明细，是财务核算的核心报表
明细分类账会计 → 报表 → 明细分类账按科目+合作伙伴维度展示明细账，支持应收/应付明细追踪
试算平衡表会计 → 报表 → 试算平衡表展示所有科目期初余额、本期发生额、期末余额
日记账会计 → 报表 → 日记账按日记账类型（销售/采购/银行/现金）查看凭证明细

5.6 财务报表

资产负债表

展示企业在特定日期的财务状况，包括资产、负债和所有者权益三大要素。

  • 路径：会计 → 报表 → 资产负债表
  • 支持按日期范围、对比期、公司（多公司）筛选
  • 可导出 PDF / XLSX，支持打印
利润表

展示企业在一定期间内的经营成果，包括收入、成本、费用和净利润。

  • 路径：会计 → 报表 → 利润表
  • 支持期间对比（本月/本季/本年 vs 同期）
  • 支持按成本中心/分析维度钻取
现金流量表

展示企业现金及现金等价物的流入与流出情况，分为经营活动、投资活动和筹资活动。

  • 路径：会计 → 报表 → 现金流量表
  • Odoo 19 采用直接法/间接法生成，需正确配置科目映射
  • 确保所有银行和现金科目正确归类到现金流量项目
注意：现金流量表需要预先完成现金流量项目的科目映射配置。请导航至 会计 → 配置 → 现金流量项目 检查映射是否完整。

5.7 税务管理

税务配置
  1. 导航至 会计 → 配置 → 税务，查看所有已定义的税种。
  2. 编辑税种：设置税率、税务类型（销售税/采购税/出口退税等）、会计科目。
  3. 税务组：可将多个税种组合（如 13%增值税 + 附加税），自动计算复合税额。
  4. 税种分配：在产品的"会计"标签页中指定默认销售税和采购税。
税务报表
报表名称路径用途
税务申报表会计 → 报表 → 税务申报按期间汇总应缴税额，支持导出税局申报格式
税务明细表会计 → 报表 → 税务明细逐笔展示每张发票/账单的税额
进项/销项税汇总会计 → 报表 → 税务分析按供应商/客户维度汇总进项与销项税额

第六章 基础配置

本章介绍进销存与财务模块运行所需的公共基础配置，供系统管理员和技术运维人员使用。

6.1 公司信息设置

操作步骤
  1. 导航至 设置 → 公司，选择或新建公司。
  2. 填写公司基本信息：名称、简称、地址、电话、邮箱、网站。
  3. 上传公司 Logo，该 Logo 将自动显示在所有报表和发票上。
  4. 配置公司财务信息：
    • 默认货币（如人民币 CNY）。
    • 默认会计科目表（选择适用的国家/地区模板）。
    • 税号（统一社会信用代码 / VAT 等）。
  5. 设置公司会计期间：定义财政年度起始月份（如 1 月或 4 月）。

6.2 币种与汇率

操作步骤
  1. 导航至 会计 → 配置 → 币种，查看所有支持的币种。
  2. 启用多币种：在 会计 → 配置 → 设置 中勾选"多币种"。
  3. 配置汇率：点击目标币种，设置对基准货币（如 CNY）的汇率。
  4. 自动更新汇率：启用"自动汇率更新"，系统每日从指定服务获取最新汇率。
  5. 汇率差异处理：月末运行"重估未结清余额"生成汇兑损益凭证。
提示：汇率更新支持 Yahoo Finance、欧洲央行、中国银行等多种数据源。在"设置"中配置自动更新频率。

6.3 税收配置

税种配置步骤
  1. 导航至 会计 → 配置 → 税务 → 新建。
  2. 填写税务名称（如"增值税 13%"），设置税率百分比。
  3. 选择税务类型：销售税（销项）、采购税（进项）、出口退税等。
  4. 配置会计科目：
    • 税务科目：记录应交税费/待抵扣进项税。
    • 折扣科目：税务折扣对应的科目。
    • 现金折扣科目：提前付款折扣对应的税务调整科目。
  5. 分配税种：在产品主数据、客户/供应商的"会计"标签页中设置默认税种。
配置项推荐值（中国会计准则）说明
销项税科目2221-01 应交增值税-销项税额销售发票上的增值税
进项税科目2221-02 应交增值税-进项税额采购发票上的增值税
税务类型销售税/采购税区分销项与进项方向

6.4 审批流设置

配置审批规则
  1. 导航至 采购/销售 → 配置 → 审批规则。
  2. 点击新建，定义审批触发条件：
    • 金额阈值：订单金额超过指定金额需审批。
    • 基于产品：特定产品（如高价值商品）的订单需审批。
    • 基于供应商/客户：特定合作伙伴的订单需审批。
  3. 选择审批人（或审批用户组），可设置多级审批。
  4. 保存后规则生效，匹配条件的订单在确认时自动进入审批状态，通知审批人。
财务审批配置
  1. 导航至 会计 → 配置 → 设置 → 审批流。
  2. 启用"发票审批"：指定发票金额超过多少时需要审批。
  3. 启用"付款审批"：指定付款金额超过多少时需要审批。
  4. 可设置差异化的审批层级（如经理审批、总监审批、总经理审批）。

6.5 用户权限与角色

用户与权限组配置
  1. 导航至 设置 → 用户 → 用户管理，点击新建或编辑已有用户。
  2. 在"访问权限"标签页中为用户分配权限组。
  3. 各模块的内置权限组如下：
模块权限组说明
采购用户：仅自身订单只能查看和操作自己创建的采购订单
用户：所有订单可查看所有采购订单
管理员完全访问权限，含配置
销售用户：仅自身订单只能查看和操作自己创建的销售订单
用户：所有订单可查看所有销售订单
管理员完全访问权限，含配置
库存用户基本库存操作（盘点、移库、查看报表）
管理员完全访问权限，含仓库配置
批次/序列号管理批次和序列号的操作权限
会计用户：仅查看只读查看财务报表、凭证
用户：开票可创建和确认发票/账单
用户：付款可创建和确认付款
管理员完全访问权限，含科目表、税务等配置
安全最佳实践
  • 最小权限原则：仅授予用户完成工作所需的最小权限集。
  • 职责分离：开票人与收款人不应为同一人；采购申请人与审批人应分离。
  • 定期审计：使用"设置 → 审计日志"功能追踪关键操作变更。
  • 密码策略：在设置中启用密码有效期、复杂度要求。
  • 多公司隔离：多公司场景下，确保用户权限按公司隔离。
