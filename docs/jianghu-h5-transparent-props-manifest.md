# 北上 H5 近景透明 PNG 摆件素材清单

> 目标工程：`jianghu-client`（Vue3 H5 壳 + 原生 DOM 摆件方案）。供美术方产出、验收方核对，**文件命名与代码键一一对应**。
> 与分层背景（`docs/jianghu-h5-assets-manifest.md` §1-2 已列）配套；本清单专管**近景摆件**的透明 PNG 规格与落码。
> 关键前提：**生成工具只能出带底色的 JPEG，无 α 通道**（本机库内无可用的抠图依赖，且不新增依赖）。因此素材产出后，透明通道需按下方 §3 两种途径之一获得，否则保留现有 SVG 剪影回退（`src` 留空，功能不受损）。

---

## 1. 六件摆件清单（单物抠净、透明底、落地）

存放：`shells/h5/public/assets/props/`

| 文件 | 对接 `point.id`（场景） | 建议像素 | 视觉母题 | 落地/姿态要求 |
|---|---|---|---|---|
| `notice.png` | `notice`（wudai） | 160×200 | 钉在木柱上的封路告示 | 立式木牌，柱根触地，墨迹向观者 |
| `jar.png` | `barrel`（wudai，shape=jar 酒坛） | 200×200 | 青瓷泥封酒坛 | 坛底半埋滩泥感，泥封突出 |
| `boat.png` | `boat`（wudai） | 320×200 | 平底渡船（老船家附于其上） | 船腹压水面、船头略上翘，不悬空 |
| `monk.png` | `monk`（longtan） | 200×240 | 守山僧 | 僧立山道，衣袂垂膝，脚下落地 |
| `pine.png` | `pine` / `pine_root`（longtan，共用一稿） | 260×320 | 山巅雪松 | 主干直、树根收束处留"根空槽"（浇潭水处） |
| `tarn.png` | `tan`（longtan） | 260×140 | 龙潭幽水面/潭口 | 横向水面，下缘沉入场景底（僧/松之后） |

补充可延后细稿：`pine_root.png`（240×280，树根/根须特写，供 `pine_root` 点独立用）。

## 2. 通用规格（所有摆件强制）

- 格式：**PNG-24 / PNG-8，α 透明通道干净**：无白底、无灰边、无黑边、无半透明发丝残留。
- 长边 ≥ 1024、2x 出图（H5 经 `object-fit` 缩放），风格 **彩墨新国潮**，与 `wudai.jpg / longtan.jpg` 底图一致。
- 单物居中、四周留 8%~12% 呼吸边。
- **底部必须留"落地处"**（触地/触水/半埋），禁止悬空漂浮、禁止带地面阴影占用过多透明区。
- 命名全小写下划线。

---

## 3. 获得干净 α 的两条途径（先出后填，不阻塞）

1. **美术/工具抠图**：在上述出图基础上用 PS/扣图工具抠净透明通道，产出 `*.png` 放入 props 目录。
2. **接受 AI 带底图 / 保留 SVG**：若走不到干净 α，保持 `src` 留空，渲染自动回退现有 `SceneProp` SVG 剪影——功能与遮挡照常，只少了贴图质感。**严禁把不透明方底图直接当透明摆件塞进场景**（会盖背景出矩形）。

---

## 4. 对接代码（素材验收后填充）

`content/src/northward.ts` 各 `point` 增 `src / size / z`（`z` 越大越靠前；不填 `z` 时按 `elemZ` 缺省「底部在前」）。示例：

```ts
// wudai
{ id: "notice", ..., src: "/assets/props/notice.png", size: 120, z: 30 },
{ id: "barrel", ..., src: "/assets/props/jar.png",    size: 110, z: 20 },
{ id: "boat",   ..., src: "/assets/props/boat.png",   size: 170, z: 24 },
// longtan
{ id: "tan",   ..., src: "/assets/props/tarn.png",  size: 200, z: 10 },
{ id: "monk",  ..., src: "/assets/props/monk.png",  size: 150, z: 40 },
{ id: "pine",  ..., src: "/assets/props/pine.png",  size: 180, z: 45 },
{ id: "pine_root", ..., src: "/assets/props/pine.png", size: 120, z: 50 },
```

- 遮挡序建议：告示(n=30) 在 酒坛(jar=20) 前；龙潭水(tan=10) 在 僧(40)/松(45) 之后。
- 保留各点原有 `on` 数组原样，只加素材字段。

---

## 5. 验收清单（透明摆件专用）

- [ ] 6 件均透明通道纯净：无白底、无灰/黑边、无发丝白雾
- [ ] 尺寸/命名/风格符合 §1-2，底部触地不悬空
- [ ] 落位核对：渡口告示在酒坛前、船压水面；龙潭水面在僧/松之后
- [ ] 填码后 `npm run dev` 冒烟：透明贴合背景、遮挡序正确、9 处交互点可点

---

## 6. 交接流向

AI 出带底稿 →（§3 通路1）抠净透明 PNG → 验收 §5 → 填 `src/size/z` → 提交 → 冒烟。走不通则沿用 SVG 回退并标记。
