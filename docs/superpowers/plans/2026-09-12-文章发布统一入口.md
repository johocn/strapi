### Task 1: 新建公共基础表单组件 `ArticleBaseForm`

- [ ] **Step 2: 修复 `model` 写绑定写法**

`model` 的 setter 与直接 v-model 语义不同。为保证 `v-model="form"` 双向，父组件应该用 `v-model="form"`，且子组件对 model 的字段直接写 `model.title`（浅引用同一对象即可同步，无需 computed setter）。因此把 `<script setup>` 改为：

```vue
<script setup>
import { computed } from 'vue'
const props = defineProps({ modelValue: { type: Object, required: true } })
const emit = defineEmits(['update:modelValue'])
// 直接透传对象引用；父组件 v-model 绑定后字段即双向同步
</script>
```

并把模板里所有 `model.xxx` 保持——但由于我们不再定义 `model`，需要改回 `props.modelValue.xxx`。**为可读性，定义别名**：

```vue
const model = computed(() => props.modelValue)
```

（只读 computed 别名，模板里 `model.title` 直接改 `props.modelValue.title` 的值即改到父对象。）

`ArticleBaseForm` 仅在被页面引入时编译。本任务无需独立构建，检查文件已保存、无语法错误即可。

`onLoad` 支持 `options.type` 预设 `form.type` / `typeIndex` / `jsonLdType`：

```js
onLoad((options) => {
  loadOptions()
  if (options?.type && typeValues.includes(options.type)) {
    typeIndex.value = typeValues.indexOf(options.type)
    form.value.type = options.type
    form.value.jsonLdType = TYPE_JSONLD_MAP[options.type] || 'Article'
  }
  if (options?.documentId) {
    documentId.value = options.documentId
    loadDetail()
  }
})
```

const TYPE_JSONLD_MAP = {

  'local-report': 'Article',
  'geo-article': 'Article',
}
