# 题库批量导入 / 练习考试 / 错题集 —— 设计文档

日期：2026-08-18
范围：Strapi（`basic` 目录，`zhao-quiz` 插件）+ 圣麟 C 端（`web` 目录）批量题库与科学练考闭环。
状态：待评审

## 1. 目标与北极星

本功能**不是**给出一套考试工具，而是建立「练习 → 即时反馈 → 错题沉淀 → 间隔重练 → 模拟考试」的**科学学习闭环**，稳定提升考试成绩。

北极星指标（可观测）：
- 客观题正确率随复习次数上升；
- 错题集 active 规模随时间收敛（错题被逐步掌握出集）；
- 模拟考试通过率 / 平均分提升。

### 学习闭环

```
练习 → 即时判分 → 错题入库 →
间隔重练 → 模拟考试 → 成绩提升 → （查漏再练，回到练习）
```

支撑闭环的两个子系统：

- **内容侧（管理后台）**：批量导入题库 → 组卷生成试卷 → 发布。
- **练习侧（C 端）**：知识点刷题 → 随机刷题 → 模拟考试 → 错题集 → 错题间隔重练。

## 2. 数据模型

延续 `zhao-quiz` 既有模型（Quiz / QuizRecord / QuizExam / QuizExamAttempt / QuizBatch），沿用 Strapi v5 Documents 模式。知识点复用 `zhao-course` 已有知识树（课程/章节/知识点），不重复建模。

### 2.1 新增内容类型 · 错题集 `wrong-quiz`

| 字段 | 类型 | 说明 |
|---|---|---|
| user | 关系→用户 | 与 `quiz` 组成唯一对（同题不重复入库） |
| quiz | 关系→题目 | 关联错题 |
| course / lesson / knowledgePoint | 关系 | 模块筛选、知识点归因 |
| wrongCount | integer | 累计做错次数 |
| status | enum | `active`(待复习) / `archived`(已掌握移除) |
| reviewLevel | integer | 间隔重复层级 1..5 |
| dueAt | datetime | 下次复习截止时间（按层级递增） |
| lastWrongAt / lastCorrectAt | datetime | 计时纠偏 |

**入集/出集规则**：
- 任一项作答判错（考试或练习）→ 已有记录则 `wrongCount+1`，否则新建 `active`。
- 同一错题在错题重练中**连续答对 3 次** × 最高层级完成 → `archived` 移出；单次答对不立即出集（防蒙对误移）。
- `archived` 保留 `wrongCount` 与历史，可回看但不进重练队列。

### 2.2 扩展 · 试卷 `quiz-exam`（组卷能力）

| 字段 | 类型 | 说明 |
|---|---|---|
| paperType | enum | `fixed`(固定题) / `rule`(规则抽题) |
| paperRule | json | 分节 `[{题型, 数量, 分值, 难度, 知识点}]` |
| knowledgeScope | relation | 题目来源范围（课程/章节/知识点） |
| shuffle | boolean | 同类题随机排序（防作弊） |

### 2.3 扩展 · 练习记录 `quiz-record`

| 字段 | 类型 | 说明 |
|---|---|---|
| mode | enum | `practice`(练习) / `exam`(考试) |
| practiceType | enum | `knowledge` / `random` / `simulate` / `wrong`(错题重练) |
| sourceQuiz | relation | 反向定位错题来源，支撑自动入库 |

### 2.4 扩展 · 批量导入 `quiz-batch`

| 字段 | 类型 | 说明 |
|---|---|---|
| course / lesson / knowledgePoint | 关系 | 整批落库归属 |
| batchCode | string | 批次标识，导出/审计用 |

## 3. 批量导入与导出格式

### 3.1 导入管线

```
上传模板 →（解析）→ 格式校验（逐行）→ 预检回执（成功/错误行明细）→ 用户确认 → 事务入库
```

- 先全量校验，返回 `成功行数 / 失败行数 + 每行错误原因`（行号定位），确认后再入库。
- 幂等去重：同课程 + 同题干判为重复，默认跳过并在回执标注「已存在」。

### 3.2 导入模板（Excel 单工作表，列固定）

| 列名 | 必填 | 说明 |
|---|---|---|
| courseName | ✓ | 课程（自动匹配或新建） |
| lessonName | ✗ | 章节 |
| knowledgePoint | ✗ | 知识点（多个用 `；` 分隔） |
| type | ✓ | 题型：单选/多选/判断/填空/简答（或英文枚举） |
| title | ✓ | 题干（支持富文本/图片占位） |
| options | 选择题必填 | `A.选项一|B.选项二|C.选项三|D.选项四` |
| answer | ✓ | 见题型规则 |
| explanation | ✗ | 解析 |
| difficulty | ✗ | `易/中/难`，默认中 |
| points | ✗ | 分值，默认 0 |

**题型规则**
- 单选：answer 单个字母。
- 多选：answer 用 `,` 连接（顺序无关，判分按集合比较）。
- 判断：answer 限 `对/错`。
- 填空：多空用 `|` 分隔，逐空给分。
- 简答：answer 为参考答案；判分走关键词自动或人工复核（可配）。

### 3.3 导出格式

复用模板结构并附加审计列：`quizId`（唯一标识，便于回导更新）、`updatedAt`、`createdBy`、`status`（草稿/已发布）。支持按课程/批次/知识点过滤导出。

**实现说明**：前端已封装 `downloadQuizTemplate`（模板下载）与 `quiz-batches` 导入批次接口，无需新增端点。

## 4. C 端练习与错题集交互

### 4.1 练习入口

| 入口 | 作答来源 | 说明 |
|---|---|---|
| 知识点刷题 | 按课程/章节/知识点 | 随课随练 |
| 随机刷题 | 范围内随机 | 泛练巩固 |
| 模拟考试 | 规则组卷 | 全真限时，走考试流程 |
| 错题重练 | 错题集 active | 只练到期待复习的错题 |

**作答交互**：客观题即时对错 + 解析 + 知识点标注；简答先提交待评（客观分即时、主观分回填）。答错立即触发错题入库/计数更新。

### 4.2 错题间隔重复（reviewLevel / dueAt）

| 层级 | 间隔 | 答对后 |
|---|---|---|
| 1 | +1 天 | 升 L2 |
| 2 | +2 天 | 升 L3 |
| 3 | +4 天 | 升 L4 |
| 4 | +7 天 | 升 L5 |
| 5 | +15 天 | **连续答对，`archived` 移出** |
| — | 层级内答错 | **等级归 1，`wrongCount+1`，重新计时** |

- 错题重练入口展示 `dueAt <= 今天` 的 active 题目，优先练最需复习的。
- 答对计数：连续答对 N 次才升级，单次答对不立即出集。

## 5. 后端组卷、前端考试与评分

### 5.1 组卷（`quiz-exam`）

| 方式 | 规则 | 适用 |
|---|---|---|
| fixed | 手工选题 + `randomOrder` 打乱 | 单元卷、正式考 |
| rule | 按 `paperRule` 分节抽题（题型+数量+分值+难度+知识点），从 `knowledgeScope` 随机 | 模拟考、防重复 |

**兜底**：某节可用题数不足，回执缺额并降级为「已抽题 + 缺额提示」，避免空卷。

### 5.2 前端考试流程

开始 → 限时倒计时（`timeLimit`）→ 逐题作答/标记 → 交卷或到时自动交卷 → 提交 `attempt` → 展示得分。`maxAttempts` 控制次数，异常刷新用 `startedAt` 兜底续考。

### 5.3 评分管线

```
考生提交 → 客观题自动判分 → 主观题判定（关键词自动 + 人工复核）→ 合并得分（总分/是否通过）→ 回流错题集
```

- 客观题（单选/多选/判断/填空）提交时自动判分，得分即时。
- 简答题：优先关键词自动初判（可配阈值），命中度低或配置人工时进入 `pending-grading` 队列，由管理员/教师复核后回填主观分，合并为总分。
- 判分结果统一回流错题集（答错即入集/计数），完成闭环最后一段。

## 6. MVP 范围与切分

首版 = **完整 MVP 闭环**（上三节全部能力，无分阶段裁剪），但遵循最小依赖原则：

- 仅使用首版必需字段；模拟考试复用现有 `quiz-exam`/`attempt` 端点。
- 不为「学情报表」「弱项雷达」等分析单独建模（MVP 期间以接口聚合数据实现，不建新表）。
- 主观题复核以工作台列表（pending-grading）交付，不做多人协同标注。

## 7. 风险与卡点

- **批量导入大文件**：Excel 解析用流式逐行，避免大文件 OOM（插件运行在低内存服务器，注意 2G 限制）。
- **错题去重唯一性**：以 `(user, quiz)` 为唯一对需在 Strapi 侧做幂等写入，防止并发重复记录。
- **主观判分阈值**：关键词自动判分对简答的准确度有限，缺省走人工复核更稳妥。
- **题量不足**：规则抽题需有兜底与缺额回执（见 5.1）。
