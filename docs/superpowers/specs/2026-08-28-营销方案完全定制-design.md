# 营销方案新增「完全定制」分支 — 设计文档

日期：2026-08-28

## 背景与目标

现有「宣传文案设计」页（`web/src/pages/activity/promo.vue`）已支持 AI 接入：AI 基于活动固定信息生成 JSON，回填为固定模块组合（`promoModules`）。格式相对固定，自由度不足。

目标：营销方案新增一个「完全定制」分支，页面内容全部由用户自由输入，C 端对内容深度过滤后展示发布的成品。两套方案通过 Tab 切换，互不影响。

## 需求点

1. **tab 两个方案**：Tab1「AI 智能生成」(现有) + Tab2「完全定制」(新增)
2. **完全定制方案**：页面所有内容由用户输入，存为富文本 HTML
3. **C 端深度过滤**：C 端只渲染安全、可发布的成品内容
4. **活动要素植入**：推荐方案将活动固定信息（标题/时间/场地/名额/费用/讲师）植入完全定制文案

## 决策（已确认）

| 决策点 | 结论 |
|---|---|
| 方案命名 | Tab1「AI 智能生成」、Tab2「完全定制」 |
| 数据存储 | 新增字段 `customPromoHtml`（text 类型），与现有 `promoModules` 并存 |
| C 端生效判定 | `customPromoHtml` 非空即优先渲染，为空回退 `promoModules` |
| 要素植入方式 | 占位符变量替换：存 `{{title}}` 原文，C 端实时替换 |

## 数据模型

在 `zhao-point` 活动 schema（`zhao-point/server/src/content-types/activity/schema.json`）新增：

```json
"customPromoHtml": { "type": "text" }
```

与现有 `promoTemplate` / `promoModules` / `promoColors` 并存。两套方案各自独立保存，互不覆盖。

> 注意：新增 schema 字段后需重新构建并部署 zhao-point 后端，否则数据库不创建新列。

## 前端（web 运营端）

### promo.vue — 双 Tab
- 顶部新增 Tab 切换：**AI 智能生成** / **完全定制**
- Tab1：现有内容不变
- Tab2：完全定制编辑区
  - 富文本编辑器（复用 `RichEditor`）
  - 「插入活动要素」工具栏：按钮列表（标题/开始时间/结束时间/场地/名额/费用/讲师/活动介绍），点击在光标处插入占位符（如 `{{title}}`、`{{startTime}}`）
  - 预览（复用 C 端 promo 呈现）
- 保存：
  - Tab1 保存 `promoModules`/`promoContact`/`promoColors`（现有逻辑）
  - Tab2 保存 `customPromoHtml`（存占位符原文，不展开）
- 加载：读 `customPromoHtml` 回填 Tab2 编辑器

### 活动要素占位符规则
- 占位符格式：`{{keyword}}`，如 `{{title}}` / `{{startTime}}` / `{{endTime}}` / `{{venueName}}` / `{{capacity}}` / `{{cashPrice}}` / `{{lecturer}}` / `{{description}}`
- 保存时原样存储占位符文本
- 未提供时占位符替换为空字符串，不输出占位符字样

> 注：uni-app `editor` 组件输出 HTML 时占位符作为纯文本子节点保留，本文案不依赖编辑器注入，仅在 HTML 文档中直接排版。

## C 端（shao/v.joho.cn）

### detail.vue — 优先渲染完全定制
宣传区块逻辑改为：

```
if (customPromoHtml 非空) 渲染完全定制（占位符已替换 + 深度过滤）
else 渲染现有 promoModules 模块组合（现状）
```

- 占位符替换：渲染前用活动固定信息 `String.replace(/{{keyword}}/g, 值)` 替换
- **深度过滤**：`<rich-text :nodes=...>` 天然剥离脚本/事件/未知标签，只渲染受支持的节点——即"完全过滤后显示发布内容"。前端不做其他篡改。

## 错误处理与兼容

- 未配置完全定制（`customPromoHtml` 空/null）的活动：行为与现在完全一致
- 占位符值缺失（如未设置讲师）：替换为空串，避免页面出现 `{{lecturer}}` 字样
- 既有活动数据无 `customPromoHtml` 字段：`undefined` 视为空，回退模块组合

## 测试要点

1. 新建活动，Tab2 输入文案并插入多个占位符 → 保存 → 重新进入回填正常
2. 保存后 `customPromoHtml` 字段在 DB 正确落库
3. C 端：`customPromoHtml` 非空时展示完全定制；清空后回退模块组合
4. 占位符随活动信息变更实时同步
5. 完全定制含异常标签（script/事件）时 C 端被剥离不显示
6. 旧活动（无 customPromoHtml）C 端展示不受影响
