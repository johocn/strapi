# RiskTip 类型扩展设计（riskType 替换 isFinance）

- 日期：2026-09-06

- 状态：已批准

- 范围：zhao-website（后端 GEO 文章 schema）+ strapi-site（前端 GEO 文章页）

## 1. 背景与目标

当前 GEO 文章页的 RiskTip（风险提示条）仅由 `article.isFinance` 布尔值触发，标签固定为"风险提示"，仅覆盖金融场景。健康、法律等文章同样需要风险提示或声明。

目标：以**扁平枚举字段** **`riskType`** 替换 `isFinance`，覆盖金融细分品类（16 种，含通用）及健康、法律、通用声明，前端按类型映射标签与默认文案。

## 3. 数据模型改动（后端 zhao-website）

`plugins/zhao-website/server/src/content-types/geo-article/schema.json`：

- 删除字段 `isFinance`（boolean）

- 新增字段 `riskType`（enum，含上表全部 19 个值，默认 `none`）

- 保留 `riskDisclaimer`（text，localized）作为自定义文案覆盖

## 4. 前端改动（strapi-site）

- `lib/geo-article.ts`：`GeoArticle` 类型 `isFinance?: boolean` → `riskType?: RiskType`；新增 `RiskType` 联合类型

- `components/modules/geo/RiskTip.tsx`：内置 `RISK_TIP_MAP`（枚举 → { label, text }）；`riskType` 为 `none` 或缺失时不渲染；`riskDisclaimer` 非空时覆盖默认文案

- `components/views/GeoArticleView.tsx`：渲染条件 `article.isFinance && <RiskTip/>` → 始终渲染 `<RiskTip/>`（组件内部自决）

## 5. 数据迁移

- 旧数据 `isFinance = true` → `riskType = 'finance-general'`

- 旧数据 `isFinance = false` → `riskType = 'none'`

- 迁移在 schema 生效后执行一条 SQL（`UPDATE geo_article SET risk_type = CASE WHEN is_finance THEN 'finance-general' ELSE 'none' END`），随后删列

## 6. 部署

- 后端：重建 `plugins/zhao-website/dist`（本地 `npm run build`），git 提交 dist 后走部署脚本；生产当前 `geo-articles` 等 GEO 接口为 404（dist 未部署），本次一并补齐

- 前端：重建 `strapi-site/out`（NEXT\_PUBLIC\_SITE\_URL=<https://www.joho.cn），跑> `deploy-www.ps1` 上线

## 7. 风险点

- schema 变更需 Strapi 重启生效；enum 字段对已存在表执行 alter 正常

- 迁移前先备份；迁移语句需与 schema 生效顺序一致（先加字段迁移数据，后删列）

- 前端文案表较长（19 条），集中维护在 RiskTip 单文件内，避免散落
