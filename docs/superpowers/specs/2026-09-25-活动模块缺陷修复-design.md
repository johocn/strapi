# 活动模块缺陷修复设计（web × zhao-point × zhao-auth）

> 日期：2026-09-25
> 范围约束：**只修缺陷**。不改表结构、不加新接口、不动统计口径（时间区间/维度/导出/趋势一律不做）。
> 前置：阶段十七（活动后运营三合一）已设计，但关闭入口前端缺失，链路实际未激活。

## 目标

修掉活动域 14 项已核实缺陷，按 3 批交付：

1. **批 1（后端内核）**：非 admin 角色可用活动域；剧本游与活动奖励积分能真正发放。
2. **批 2（前端可达性）**：活动关闭入口可达并激活活动后运营链路；孤儿页可达；列表不再静默丢数据。
3. **批 3（一致性）**：停用资源可恢复；状态/口径一致性收口。

## 批 1 · 后端内核（basic 仓库）

### 1.1 权限点补齐

**改动 A：zhao-auth `server/src/permissions.ts`**

新增权限树节点（顶层，与 `menu.point-center` 同级）：

```ts
"menu.activity-center": {
  label: "活动中心",
  type: "menu",
  children: {
    "menu.activity": {
      label: "线下活动",
      type: "menu",
      children: {
        "activity.read":   { label: "查看活动", type: "button" },
        "activity.create": { label: "新建活动", type: "button" },
        "activity.update": { label: "编辑活动", type: "button" },
        "activity.delete": { label: "删除活动", type: "button" },
      },
    },
    "menu.activity-series": {
      label: "活动系列",
      type: "menu",
      children: {
        "series.read":   { label: "查看系列", type: "button" },
        "series.create": { label: "新建系列", type: "button" },
        "series.update": { label: "编辑系列", type: "button" },
        "series.delete": { label: "删除系列", type: "button" },
      },
    },
    "menu.activity-resource": {
      label: "讲师/场地",
      type: "menu",
      children: {
        "resource.read":  { label: "查看资源", type: "button" },
        "resource.write": { label: "编辑资源", type: "button" },
      },
    },
  },

```

- `MODULE_MANAGER_MAP`（同文件 :38-48）增：`activity: ROLES.POINT_MANAGER`（复用现有角色，不新增角色）。键名必须为 `activity`，与 `web/src/constants/module.js:20` 的模块 key 一致。
- `DEFAULT_ROLE_PERMISSIONS`（:1686-1687）改为：
  - `[ROLES.POINT_MANAGER]: centerPermissions("menu.point-center").concat(centerPermissions("menu.activity-center"), ["auth.admin-login"])`
  - `[ROLES.POINT_EDITOR]: centerEditorPermissions("menu.point-center").concat(centerEditorPermissions("menu.activity-center"), ["auth.admin-login"])`
- `ROLES` 不新增条目。

**改动 B：zhao-point `server/src/permissions.ts`**

在 `PERMISSIONS`（:13-48）补 `activity.read/create/update/delete`、`series.read/create/update/delete`，`allowRoles` 与路由声明的角色档位一致（read 含 PLUGIN_MANAGER；create/update 含 CHANNEL_ADMIN、PLUGIN_MANAGER；delete 仅 ADMIN、CHANNEL_ADMIN），与既有 `resource.read/write` 保持同一风格。

**影响面**：后台「角色管理」将出现「活动中心」节点，需重新给各角色勾选；admin 靠短路放行不受影响。

### 1.2 积分规则键补全

zhao-point `config/index.ts` 的 `increaseRules`（:55-62 活动类区块）追加：

| action | points | limitPerDay | isOneTime | description |
|---|---|---|---|---|
| `activity_reward` | 0 | 0 | false | 活动奖励发放(动态积分) |
| `tour_checkin` | 10 | 0 | false | 剧本打卡 |
| `tour_main` | 50 | 0 | false | 剧本谜底破解 |
| `tour_finale` | 100 | 0 | false | 剧本终章兑奖 |

`points` 与 `activity.ts` 中 `act.story?.stationPoints ?? 10`、`?? 50`、`?? 100` 的兜底值对齐。

**生效方式**：`bootstrap.ts:28-49` 按 action 幂等 seed 到 `point-rule` 表，插件重启即自动补齐，**无需运维手工建规则**。

## 批 2 · 前端可达性（web 仓库）

### 2.1 关闭活动入口

- `api/activity.js` 增 `closeActivity(documentId)` → `POST ${ADMIN}/activities/${documentId}/close`。
- `list.vue` 卡片操作区对 `status === 'ongoing'` 显示「关闭活动」，二次确认文案明示「关闭后将按到场情况触发回执/挽回/复购触达，并生成经营台账快照」。

### 2.2 孤儿页接线

`dashboard/index.vue` 活动管理区块增「咨询留言」入口 → `/pages/activity/consultation-messages`。

### 2.3 列表服务端分页 + 搜索

- 后端 `adminList`（controllers/activity.ts:506-526）在本地 `filters` 对象内追加过滤，避免被 spread 覆盖：
  - `search` → `title: { $containsi: search }`
  - `venue` / `lecturer` → `{ documentId: { $eq: value } }`
  - `category` → `category: { $eq: category }`
  - 保留既有 `status`、`documentIds`、`pagination`、`sort`
- 前端 `list.vue`：
  - 顶部增标题搜索框（回车/点搜触发）
  - 分页改服务端：`page`/`pageSize:10` 下发，分页器读 `extractList` 返回的 `pagination.total`
  - 场地/讲师/分类筛选由客户端 `filteredAll` 改为 query 参数下发
  - 保留 `onShow` 重新加载

### 2.4 冲突预检字段对齐

`form.vue` 的 `fmtRange` 兼容 `suggestStart` / `suggestEnd`（保留对 `startTime/endTime`、`start/end` 的兼容分支）。

### 2.5 临时授权用户 ID 校验

`temp-auth.vue`：提示文案与输入校验统一为「数字用户 ID」，提交时 `userId: Number(value)`，非数字直接前端拦截并提示。

## 风险

1. **权限树改动会进后台角色管理**：非 admin 角色需重新勾选活动权限；上线后应通知运营做一次角色配置核对。
2. **dist 部署铁律**：批 1 改的是插件源码，必须 rebuild zhao-point 与 zhao-auth 的 dist 并一并提交，否则静默失效。
3. **改 `adminList` 过滤有回归面**：`getActivity`（`form.vue`/`promo.vue` 复用）走 `documentIds`+`pageSize:1`，需回归建/改活动与宣传页加载。
4. **2G 服务器禁止构建**：dist 在本地构建后 scp。

## 挂账（明确不在本轮）

- **统计能力缺口**：时间区间、场地/讲师/类型维度、现金收支汇总、趋势序列、导出、`attendPointsGlobal` 按活动分摊 —— 本轮不动。
- **C 端 `tour` 模块白名单缺失**（shao/wealth 仓库），需另开任务。
- **并发/幂等 4 项**：报名占位与写库非同一事务、并发签到撞 `activity-attendance` 唯一索引、候补转正重复发联系方式/问卷积分、台账 auto 快照与系列场次生成并发重复。
- **返回结构不统一**：`{rows,summary,pagination}` vs `{data,meta}`。
- **`adminUpdate` 无状态流转校验**（可非法跳转绕过 closeActivity 收尾）。
