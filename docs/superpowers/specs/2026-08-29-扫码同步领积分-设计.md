# 扫码同步领积分 + 问卷飘分 设计文档

日期：2026-08-29
状态：已确认（待实现）

## 背景与目标

C 端活动详情页（`v.joho.cn/#/pages/activity/detail`，shao/detail.vue）报名成功后进入「领取更多权益」区，目前存在以下问题：

1. **问卷领积分无反馈**：答完问卷后积分 +50 已到账，但权益卡不显示「已领」，也没有任何动态效果。根因：`submitFillQuestionnaire` 提交成功后未调用 `loadSignupUnlock()`，`surveyDone` 不刷新，卡片停留在「填写问卷 / +50」态。
2. **关注公众号领积分断裂**：
   - PC 端「关注公众号」权益卡里**从不渲染二维码**（`wxQrcodeUrl` 已从后端加载但模板未使用，`benefit-inline` 只写文字＋「我已关注，刷新领取」按钮）。
   - 微信永久带参二维码数量有限，需用**临时码**。
   - 扫码关注后缺少与当前用户的关联，电脑/手机不同步，有割裂感。

目标（本 spec 三件事）：
- 问卷提交后刷新权益态并展示 `+50 飘分` 动画。
- 关注公众号生成**按用户缓存的临时带参二维码**并真渲染在权益卡内。
- 扫码关注后**自动判定已领**（轮询），电脑/手机同账号同步显示「已领 +50」，保留手动刷新按钮兜底。

## 架构约束

- 活动逻辑全部落在 **zhao-point**（单向依赖，不反向），**不改 zhao-sso 事件处理器**。
- 复用 zhao-sso 已有关注链路：关注事件把 openid 的 `sso-third-party-binding.subscribe` 置 1；zhao-point `hasSubscribe` 经 `refreshSubscribe`（cgi-bin `user/info`）反查，关联到当前用户。
- 临时带参二维码复用 zhao-sso `sso-wx-qrcode` 服务的 `create(kind:'temporary')`。

## 组件与数据流

### 1. 问卷飘分 + 已领状态刷新（纯前端）

- `submitFillQuestionnaire` 提交成功后：
  1. 调 `loadSignupUnlock()` 刷新 `unlockCtx`，使 `surveyDone=true`。
  2. 权益卡 `survey` 项由 `未领` 翻转为 `已领 +50`。
  3. 触发 `+50` 飘分动画（CSS，卡片内浮起数字上升淡出，H5/小程序通用）。

### 2. 关注公众号临时二维码

后端（zhao-point 新增）：
- 接口：`GET /my/activity/follow-qrcode?activityId=`
- 处理：按用户缓存复用——先查该用户在本活动有效期内是否已有二维码（scene_key = `follow:act:{activityId}:{userId}`），有则直接返回；无则调 zhao-sso `sso-wx-qrcode.create({ scene_key, kind:'temporary', expire_seconds:30天, title })`，返回 `wx_url`。
- scene_key 用于标识「哪个用户」，配合缓存复用，有效期内不重复建码。

前端（detail.vue）：
- 「关注公众号」权益卡展开时，调上述接口并在 `benefit-inline` 内用 `<image>` 渲染 `wx_url` 二维码。
- `followEnabled` 逻辑保留（无码则显示提示）。

### 3. 扫码同步（自动判定）

- 当「关注」面板打开（`showSubscribeFill=true`）且 `subscribed=false` 时，启动**轻量轮询** `getSignupUnlockStatus`（约 4s）。
- 用户扫码关注后，微信事件将 openid 的 `subscribe` 置 1；轮询命中 `subscribed=true` → 自动调 `claimSubscribe` 记 +50 并触发飘分，权益卡翻转为「已领」，**立即停止轮询**。
- 电脑/手机为同一账号（同一 openid 绑定）时，两侧下次刷新/重扫均显示已领。
- 保留「我已关注，刷新领取」按钮作手动兜底。

## 关联锚点与已知边界

- 关联锚点为「该微信 openid 已绑定到当前账号（sso-third-party-binding）」。
- 边界：用户用非微信账号登录（如手机号）后，再用另一微信扫码关注，openid 不落在该账号 → 判定不到。本 spec **不做** qrscene→userId 兜底写库（需改 zhao-sso 事件侧，改大）；如后续需要再加。

## 验收标准

1. PC 报名成功 → 「领取更多权益」区显示；点「填写问卷」提交 → 卡片翻转为「已领 +50」并出现飘分。
2. PC「关注公众号」卡内出现二维码（临时码，可扫码）。
3. 手机微信扫码关注 → PC 端约数秒自动显示「已领 +50」（无需手动点按钮），手机同账号亦可见。
4. 微信「我已关注，刷新领取」按钮仍可手动领取。
5. 临时码按用户缓存，重复进入页面不重复建码。
