# SSO 登录回传邀请码与来源页回跳设计 20260905

## 背景

H5 微信分享链路（带邀请码）→ 新用户 SSO 登录注册 → 建分销 → 回跳来源页。
分销关系建立（buildReferralRelation，凭 invite\_code 反查）与 share 链接（appendInviteParams，已带 inviteCode+inviterId）均已就绪。
剩余两个断点：

1. **断点①**：SSO 登录换 token 时（exchangeToken / token 端点）返回的 user 是裸 sso\_users 行，不含用户自有邀请码。`handleCallback` 内部明明已算出 ownInviteCode 却在 controller 解构时丢弃。C 端 `getInviteCode()` 读 `user.inviteCode` 为空 → 分享退化为前端自造临时码。
2. **断点②**：`redirectToSso()` 调 `buildSsoRedirectUrl(config)` 不传 state，登录后一律回首页，无法回到分享落地/来源页。

## 修复①：登录返回注入真实邀请码

- 位置：`plugins/zhao-sso/server/src/controllers/oauth-controller.ts` 的 `exchangeToken`（前端代理换码，微信/密码/短信三条路径汇聚点）与 `token`（标准 OAuth2 端点）。

- 逻辑：`findById` 后调 `sso-invite.ensureOwnInviteCode(user.id, app_code)`（幂等：有码返回、无码生成），同时注入 `user.inviteCode` 与 `user.ownInviteCode`。

- 隔离合规：仅读 sso\_invite\_codes（sso\_ 前缀表），不碰他域。

- C 端契约：auth-callback `setUser(user)` 后，`getInviteCode()` 即取到真实码。

## 修复②：SSO 跳转携带来源页 state

- 位置：`shao/pages/login/login.vue` 的 `redirectToSso()`。

- 逻辑：跳转前从 `getCurrentPages()` 取上一页（排除 login 类页面），拼 `/{route}?{options 编码}` 作 state；无上一页时回退 `options.redirect`；均无则不传（回首页，维持现状）。

- 回跳管道（已存在无需新写）：buildSsoPageUrl 把 state 编码进 return\_url → SSO login-callback 透传 → C 端 auth-callback 检测 state 后 `reLaunch`（校验 `/` 开头防外跳）。

## 部署要点

- zhao-sso 改源码必须本地重建 dist 并随 git 提交（插件 dist 部署铁律）。

- 前端 shao 需 vite 构建后走 deploy-h5.ps1 发布。

## 验收

1. 新用户从带码链接进入 → SSO 微信登录 → exchange-token 响应 user.inviteCode 非空且等于 sso\_invite\_codes 中该用户自有码。
2. 从活动详情页跳登录 → SSO 登录成功 → reLaunch 回活动详情页（非首页）。
3. 直接打开登录页登录 → 回首页（现状不变）。
